Tensor API

Tensors are the multi-dimensional arrays that form the backbone of FerricML. They support efficient mathematical operations on CPUs and GPUs.

Creating Tensors

You can create tensors from raw data or using factory methods:

use ferricml::prelude::*;

// From a slice
let x = Tensor::from_slice(&[1.0, 2.0, 3.0, 4.0]);

// Special factories
let zeros = Tensor::zeros(&[3, 3]);
let rand = Tensor::randn(&[5, 5]);

Basic Operations

FerricML supports standard arithmetic with broadcasting support:

let a = Tensor::ones(&[2, 2]);
let b = Tensor::ones(&[2, 2]);
let c = &a + &b; // Element-wise addition

Device Management

Move tensors between hardware backends seamlessly:

let x_cpu = Tensor::randn(&[100, 100]);
let x_gpu = x_cpu.to_device(Device::Cuda(0));
