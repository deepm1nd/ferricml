Getting Started

Welcome to the FerricML documentation. FerricML is a high-performance machine learning platform built natively in Rust.

Installation

1

Add Dependency

Add FerricML to your Cargo.toml:

[dependencies]
ferricml = "0.1"
2

Select Backend

To enable GPU support, use feature flags:

# For CUDA
cargo add ferricml --features cuda

# For ROCm
cargo add ferricml --features rocm

Hello World Example

Create your first tensor and perform a simple calculation:

use ferricml::prelude::*;

fn main() {
    let a = Tensor::from_slice(&[1.0, 2.0, 3.0, 4.0]);
    let b = Tensor::ones(&[4]);
    let c = &a + &b;
    println!("Result: {:?}", c);
}
