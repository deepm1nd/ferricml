Get Started View Code
cargo add ferricml
main.rs 
use ferricml::prelude::*;

fn main() {
    // Pure Rust, AOT Autograd, Heterogeneous Compute
    let model = MnistNet::new();
    let images = Tensor::randn(&[64, 1, 28, 28]);

    let output = model.forward(&images);
    let loss = output.cross_entropy(&labels);

    loss.backward(); // Ahead-of-Time Gradients
    optimizer.step();
}

Extreme Performance

Leveraging RMLC (FerricML Compiler) and Multi-level IR dialects to squeeze every bit of power from your hardware.

Production Safety

100% Rust memory safety combined with compile-time ShapeGuards ensures your models run reliably everywhere.

Universal Compute

Native support for CPU (LLVM), CUDA, ROCm, and TPU. Deploy from serverless to edge with a single binary.
